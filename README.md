# Custom Armor Mod

Enhance your Minecraft experience with custom armor and comprehensive player stats.

## Features

- Custom armor sets with unique properties
- Stats command to display player statistics

## Requirements

- Minecraft 1.21.4
- Fabric Loader 0.14.22 or higher
- Fabric API 0.92.0+1.21.4

## Installation

1. Download the mod JAR file from the releases page.
2. Place the JAR file in your `mods` folder.
3. Launch Minecraft with the Fabric profile.

## Usage

### Custom Armor

- Craft or obtain the custom armor pieces: Custom Helmet, Custom Chestplate, Custom Leggings, and Custom Boots.
- Equip the armor to gain its unique properties.

### Stats Command

- Use the `/stats` command to display your player statistics.

## Configuration

The mod does not have a configuration file. All settings are hardcoded in the mod.
